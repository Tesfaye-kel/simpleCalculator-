# Amazing Things Start with Small Projects

This is the day I came into the world of website development. I started with a simple calculator, and even though it looks small, it taught me the basics of HTML, CSS, and JavaScript.

This project is more than just a calculator. It is my first step toward building real websites and understanding how front-end code works together.

## Features
- Clean and modern design
- Responsive layout
- Basic arithmetic operations
- Clear button and error handling
- Beginner-friendly code structure

## Files
- `calculater.html` - page structure
- `style.css` - visual styling and layout
- `script.js` - calculator logic and behavior

## How to run
1. Open `calculater.html` in your browser.
2. Click the buttons and try simple calculations.
3. Learn how each part works together.

## Why this project matters
This is a simple project, but it helped me understand:
- how HTML creates content
- how CSS makes it look beautiful
- how JavaScript adds real functionality
